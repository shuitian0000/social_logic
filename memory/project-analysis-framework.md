## 理论基础

- **吴思**: 元规则、潜规则、血酬定律、法酬公式、官家主义、顶残
- **布迪厄**: 四资本(经济/文化/社会/象征)、惯习、场域、象征暴力
- **格兰诺维特**: 弱关系力量；**伯特**: 结构洞；**边燕杰**: 强关系假设
- **阿克洛夫**: 信息不对称；**资源依赖理论**
- **四差理论**: 信息差→认知差→资源差→执行差
- **天涯神贴**: 三层认知时间差、阶层跃升三关、底层认知障碍、资本锁死规则
- **幸存者偏差**: 看到的成功≠普遍规律
- **社会分配三层逻辑**: 按劳(底层)/按资(中层)/按权(顶层)
- **利益分析法**: 一切社会现象背后都是利益驱动
- **混社会三条红线**: 不碰上层利益、中层体面、下层生计
- **刘润《底层逻辑》**: 五大底层逻辑、是非三视角、人生商业模式=能力×效率×杠杆
- **本质思考力**: 三层次+5Why+MECE+穆勒五法
- **飞轮效应**(Collins): 启动阻力最大→加速递增→自sustaining
- **投资性消费**: 心价比vs性价比；消费从"为了拥有"转向"为了成为"
- **搭子/零糖/素颜/人机社交**: 2025年年轻人社交新形态
- **段永平"不为清单"**: 不盲目扩大能力圈、不超2决策/年、不投不懂的、不走捷径
- **时间管理矩阵**: 重要/紧急四象限+GTD+PDCA
- **kkndme天涯帖**: 房地产底层逻辑(土地财政/货币蓄水池/阶层固化)
